# 角色视觉规范：原设与本地 Q 版

本表区分社区原设与本地 Q 版贴纸系列的视觉约定。生图前查看目标角色参考图与源表情，明确两者分别负责「身份/服装」与「动作/笔触」。数值色板与腰宽是既有 `cat_*` 系列的约定，不覆盖用户选定的其他版本或姿态。社区原设出处与校验哈希见 [`../resources/zipzippipe/sources.json`](../resources/zipzippipe/sources.json)（参考图文件本身仅存本机，不随 npm 包分发）。

---

## 1. 通用画风规范（蜡笔手绘 Q 版贴纸风）

| 维度 | 硬性要求 | 严禁出现的错误 |
| :--- | :--- | :--- |
| **画布底色** | 优先真实透明 RGBA；仅白底稿走 `process` | 不把棋盘格或实色背景误当透明，不重复抠原生透明图 |
| **外白边** | **默认无贴纸外白边（No outer white border）**，最终导出 `256×256` 透明 RGBA PNG | 除非用户明确要求，严禁在外轮廓外再套一圈白边或阴影 |
| **线条质感** | 略带颗粒感的手绘蜡笔 / 粗彩铅深色描边（`#2D1636` 深梅紫或 `#1E2B4D` 深藏蓝） | 严禁生硬矢量细线、厚涂无描边、3D 渲染感 |
| **上色与光影** | 哑光平涂柔和粉彩色块；简洁眼神光按源表情保留 | 避免把正常比例原设的写实光影或复杂玻璃眼照搬成 Q 版 |

## 2. 哈基米猫娘（`cat_*`）人设规范

**本机可选参考图**（若已缓存于 `<SKILL_ROOT>/resources/` 或 `<cwd>/stickers/`）：
- 全身与发色基准：`<SKILL_ROOT>/resources/hakimi_canonical_full.png`
- 胸腰裙局部放大：`<SKILL_ROOT>/resources/hakimi_torso_skirt_zoom.png`
- 已入库笔触基准：`<cwd>/stickers/cat_看书.png`、`cat_认栽.png`、`cat_好耶.png`

### 2.1 发色、猫耳与头饰（统一 `蓝粉紫` 渐变）
- **三段柔和渐变发色**：
  - 头顶、刘海与猫耳外侧：**清冷矢车菊蓝紫（Cool Periwinkle-Blue `#A0ACEA`）**；
  - 中段长发与两侧盘发团子：**绣球蓝紫（Hydrangea Blue-Lavender `#B6ACEA`）**；
  - 发尾尖端：**柔和兰花粉紫（Pastel Orchid-Pink `#E2B6EA`）**。
  - **红线**：严禁画成暖洋红顶或纯粉红头发。
- **猫耳与呆毛**：头顶一根向上微弯的呆毛；一对大猫耳（外侧矢车菊蓝紫 `#A0ACEA`，内耳浅樱粉 `#F7C6D2` + 白色绒毛簇），**绝对不能画人类耳朵**。
- **发型结构**：两侧耳朵下方各盘一个圆润螺旋发团（Coiled side buns），后侧垂落蓬松微卷长发。
- **星形发饰**：画面右侧（角色左耳下方）佩戴一枚**金边粉蓝紫渐变的「四角星 `✦`」发卡**（下方可缀一粒迷你小四角星）。**严禁画成五角星 `★`！**

### 2.2 异色瞳与五官
- **异色瞳方向（以看图者视角为准）**：
  - **画面左侧（角色右眼）**：哑光浆果粉红 / 玫红（Matte Berry-Pink `#B84B7C` ~ `#C95B8B`）；
  - **画面右侧（角色左眼）**：哑光琥珀金黄（Matte Ochre-Gold `#DEAC4B` ~ `#E5B85B`）。
- **眼白与眼神光**：
  - 冷面看书等表情不额外加白色高光；求夸、兴奋等可以随源图保留简洁眼神光；
  - **是否有眼白取决于源梗图**：若源梗图是冷面死鱼眼/豆豆眼（如《认真看书》），去掉眼白、缩小瞳孔（约常规 `0.8×`）以还原无神感；若是委屈/震惊大眼梗图，按源梗图比例保留眼白。

### 2.3 服装解剖
1. **平胸体型**：胸部平坦利落，不画乳沟、隆起弧线或紧身撑起感。
2. **上半身挂脖露肩短上衣**：
   - 深紫黑/暗夜蓝底色（`#282742`）配细金边；
   - 中式小立领，咽喉正中扣一粒迷你四角星 `✦`；
   - **胸口正中是扁平白色菱形镂空/白衬块（`◇`），白块中心有一颗金边蓝紫四角星 `✦`**（不画成盘扣卷草纹）。
3. **腰封与菱形露脐小腹**：
   - 胸衣下缘衔接**倒 V 形（`/\`）浅紫腰封（`#BA93EC`）**，正中嵌一颗较大四角星 `✦`；
   - 露出平坦纤细的菱形小腹与一竖短肚脐线（小腹宽度约头宽 `28%~34%`）；
   - **分离式宽袖**：露肩设计，大袖套套在手臂中段，袖子、后发与腰腹/裙摆之间保留清晰的背景空隙（Cutout Corridors），避免衣服跟头发粘成深色块。
4. **A 字百褶短裙（构图截断线低于肚脐时画出裙头）**：
   - 向外微张的 A 字伞裙轮廓；
   - **深紫前裙片（`#2A2F50`）与两侧/下摆浅色白紫百褶条纹（`#F1EEFB`）相间交替**；
   - 两侧胯部各饰一颗四角星 `✦`，前裙片上方垂挂纤细金色腰链与中心小四角星 `✦`。
   - *抠图提示*：浅色百褶裙衬接近白色，白底稿调用 `process` 时将该区域加入 `--protect-boxes`。

## 3. 大肥鱼鲸娘女仆（`fish_*`）人设规范

**本机可选参考图**：`<SKILL_ROOT>/resources/feiyu_canonical_maid_ref.png`

### 3.1 外观与服饰特征
- **发色与发型**：明亮钴蓝 / 海蓝色短发（`#4A69BD` ~ `#5B78C7`），头顶有一根圆弧呆毛，两侧发梢向外微翘。
- **鲸鳍耳与鲸尾（核心物种特征）**：
  - 头部两侧长着**上蓝下白（带波浪白边）的鲸鱼胸鳍状侧耳**，斜向下张开，不画人类耳朵或猫耳；
  - 身后露出上翘的**蓝色双叶鲸鱼尾鳍**。
- **黑白蓝女仆装**：
  - 头戴**白色荷叶边女仆发箍**，画面右侧（角色左耳上方）系一枚**天蓝色蝴蝶结**；
  - 深藏蓝女仆裙配白色荷叶边领口、白色围裙与白色蓬松袖口；
  - 胸前领口系**深藏蓝蝴蝶结，中心嵌一枚蓝色菱形宝石胸针**。

### 3.2 表情基调
- 既有系列以面无表情豆豆眼 / 半眯死鱼眼 / 礼貌微笑的反差感为主；「求夸」「好耶」等正向情绪表情则随源图自然表现，不强行套用死鱼眼。原设长发女仆与本地短发 Q 版按当次指定版本选用。
